# SC2MAKER

This program will allow you to format Licensed sony memory cards into SoulCalibur II Conquest cards for the namco System246

![GitHub Downloads (all assets, all releases)](https://img.shields.io/github/downloads/israpps/SC2MAKER/total?style=for-the-badge&logo=github&logoColor=white&labelColor=black)

## Translations

The program offers several language files...

By default, the program loads `lang/english.lua`

If you wish to use one of the alternative languages, please rename the file to `override.lng`

so for example, if you like spanish: `lang/spanish.lng` renamed as `lang/override.lng`
