
The program offers several language files...

By default, the program loads `lang/english.lng`

If you wish to use one of the alternative languages, please rename the desired file to `override.lng`

so for example, if you like spanish: `spanish.lng` should be renamed as `override.lng` (always inside the `lang/` folder)

then run the program

Would you like to collaborate with a translation?

download the english language file, translate it and submit a pull request. if you don't like github, send over discord
